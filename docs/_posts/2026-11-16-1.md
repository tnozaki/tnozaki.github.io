コード読むのも飽きたので先日買った報告してそのまま放置してた Fujitsu LIFEBOOK A574/M をセットアップして気分転換を図る。

## 不満点ゾロゾロ

初っ端からフラットパッドの癖の強い操作感に血管キレそう、MacBook の真似なのかクリックはフラットパッドをタップしろって思想がまず嫌い。
右クリックしたつもりがタップになってしまって左クリックメニュー出てきちゃうから故障疑って部品注文かけるか半日悩んだぞクソが。

指は両手で 10 本あるのに 1 本だけで操作が理想って、お前は指 1 本で演奏する 80 年代のシンセポップバンドのキーボード奏者かなんかか？
デュラン・デュランのニック・ローズだってもっと使うわ、指 2 本くらい。

タップ使えよ左右クリックボタンはオマケとばかりに一体成形になってるのも酷い、これ別途マウスを買わせるため採用してんですかね(陰謀論)。
よっぽど不評だったのか次の A576 では独立型の左右クリックボタンが復活してるのも当然といえる。

つーか CardBus スロット付きの A576 が売ってるの見つけてしまったので、買い替えするのもありな気がしてきたゾ。
即買いしなかった理由は A576 は CPU 直付けだからアップグレードが困難なのに載ってるのがセロリンというオチ、それに DDR4 だからメモリ増設で経済的に死ぬしな…

それにジェスチャーもデフォルト有効になってることも相まって混乱の極みである、指の本数でスクロールとかスワイプとか要らんのですわ。
しかも UEFI/BIOS レベルでタップもジェスチャー無効にできねえ地獄、うーん投げ捨てたくなってきた…

それと無線 LAN がデバマネに出てこない事に悩んだのだが、そもそもオプション装備だったというこれも酷いオチ。
アンテナマークのインジケータ―が緑点灯してるのにどういう事なの…

まぁ 15.6 インチなんてデカブツは省スペースデスクトップとしてしか使わねえんだから有線 LAN ありゃいいだろというのはそう。
でもいちおうモバイル目的で買ったんすよこれ、もうスタジオとかライブハウスに持ってく機会はまず無いと思うけど。

これ増設するにしても内にアンテナ線あるんかなこれ、バラすの結構手間かかる作りだし一緒に CPU もクアッドコア換装と SSD も 480GB にしたいけど金無いんだよね。

そんで i5 搭載モデルは Intel Management Engine (ME) という悪の枢軸ステイツによるバックドアがあるはずなんだが UEFI/BIOS 項目無くてパス変更も無効にもできねえのだよな、デバイスマネージャからは見えてるんだがファーム更新もエラーになる。
これ実は生きててデフォルトパスワードも変更できない状態だったら目も当てられんな、Intel vPro 対応 WiFi 刺すと項目が生えてきたりするんかね。
あとマニュアルに ME 管理したけりゃ SystemWalker 買えなどとあって隙あらば無知蒙昧な企業相手にベンダロックインを仕掛けるあの会社らしさにもはや懐かしさすら覚える。

TPM は UEFI/BIOS からもデバマネからも存在確認できないので静脈センサー/指紋認証ユニットと一体なんだろう、配置的に CardBus スロット排他っぽいっすね。
まぁオンボだったところで 1.2 だからどうでもいいか。

## OS 再インストールしてみる

セキュアブートとかめんどくさいだけだし、いわゆる Legacy モードちゅーやつに設定する。

* Security -> Secure Boot Configurations -> Secure Boot Option [Disabled]
* Advanced -> Boot Configurations -> CSM [Enabled]

と変更すればいい、これで MBR しかない Windows 7 もインストール可能になる。

xHCI ドライバが Intel 公式ダウンロードから消されてる上に Microsoft Update Catalog にも登録無いので Internet Archive に頼るしかないのがちょっとアレ。
自分は VMware の xHCI エミュレーションを Windows 7 で動かす用にダウンロード済だったからどうでもいいや。

あとこのドライバは Intel の古いドライバにありがちな ZIP アーカイブのセキュリティフラグを引き継いだまま実行ファイルをインストールしてしまうバグがあるので、そのままだとスタートアップアプリが起動時に警告ダイアログを出すので注意。
ZIP アーカイブを右クリック→セキュリティ→許可するをチェックしてから展開する必要がある。

8/8.1 の場合は SM バス コントローラー以外は Windows Update で降ってくるのでそれだけ上記のチップセットドライバ使えばいい。

Windows 11 からは Hypervisor-protected Code Integrity (HVCI) いわゆるメモリ整合性とかコア分離と呼ばれる機能がデフォルト有効なので、対応してない FUJ02B1 ドライバなどが動作しないはずである。
そもそも Windows 11 の要件満たしてないから無理矢理入れたら HVCI は無効化されるはずだしどうでもいいや、このマシンで使う予定の E-MU 1616M ドライバだって動かねえし。

## OS ライセンスについて

メモリのフタに銀青の Pro Windows のステッカー貼ってあるから、デザインからして 8.1 プリインストールだろうと思い込んでたけど 10 だったわ、水色になったのはもっと後なんだな。
8.1 入れても自動認証しないし手動で認証してもキー違う言われるしもしかして不正ライセンスじゃねと疑ってしまったわ、すまんな中古業者。

音楽用以外は openSUSE にしたからライセンス余ってるので不正ライセンスだったとしても新規に買うまでも無かったんだけど、使えるライセンスがある事はいいことだ。

新品購入時に 8.1 Pro を選択した場合は 7 と違って 8.1 にはダウングレード権という概念が存在しないので 10/11 で認証通ってたとしたら無償アップグレードによるもの。
この場合 UEFI/BIOS 上のプロダクトキーは 8.1 のままハードウェア ID を使ったオンライン認証になる(プロダクトキーはデフォルトキーと呼ばれる VK7JG-NPHTM-C97JM-9MPGT-3V66T で万人共通)。
よって無償アップグレードによって 8.1 の自動認証が通らなくなる事はない。

UEFI/BIOS 上のプロダクトキーは WMIC から取得可能。

```cmd
wmic path softwarelicensingservice get OA3xOriginalProductKey
```

プロダクトキー無しモデルを不正な手段でアクティベーションしたのであれば、無償アップグレードと同じデフォルトキーになるはずである。
またボリュームライセンスの不正なバラ売りならそもそも Windows 10/11 の認証が再インストールで通らない。

7 へダウングレードする場合、ACPI テーブルに Software Licensing Description Table (SLIC) があるので System-Locked Pre-installation (SLP) による認証が可能。
そっか SLIC 2.x と SLIC 3.0(Digital Marker) って同居できるって事まで思い至らなかった。
新規購入時に選択せずとも EULA 的にダウングレード権はあるのだけれど、 OEM キーと OEM ライセンス証明書入手するにはリカバリメディアが必要。
