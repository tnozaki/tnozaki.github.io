title: Bitwarden 10.1 以降は SSE4.2 が必須で古い PC で動かなくなる
---

Bitwarden デスクトップとブラウザアドオン両方で 10.1 での更新が原因で SSE4.2 非対応の CPU で動作しなくなってイライラ。
デスクトップはずっとローディング画面のままになるしブラウザだと WebAssembly が実行できないって表示される。

[Issue #24293](https://github.com/bitwarden/clients/issues/24293)
で公式アイコンが知らねーよそんな粗大ゴミ捨てろと言ってるのだが、スレッド追ってくと
[プルリク](https://github.com/bitwarden/clients/commit/15b3cc4f2952828721d4f8fce3d7e653548239d4)
通ってるから 2026.11.0 で直るっぽい。

つーかたった今 2026.10.4 がリリースされたので 2026.11.0 って来月になるのかこれ、10.1 で入った問題の解決が 11.0 まで出ないってどんなリリース管理なのこれ…

まぁいいや時間かかりそうだし古いのに巻き戻すしかねえ、影響を受けるのは Node.js/Electron で動くデスクトップクライアントと Firefox 用のブラウザアドオンのようだ、Edge は動いてる Chrome は知らん。

デスクトップは Windows なら環境変数に

```cmd
BITWARDEN_NO_UPDATER=1
```

を追加し 2026.10.0 を再インストールすればいい。WinGet や ストアは使ったこと無いからそっちから入れる場合は知らん。

Linux 版については公式バイナリが今時 .rpm/.deb を手動インストールしろという頭の悪い配布形態なので、勝手にアップデートされる事は無いから再インストールするだけでいいはず。
念のためバージョンロックしたいなら俺の使ってる openSUSE であれば以下のコマンドを叩く。

```shell
# zypper addlock bitwarden
```

Snap や AppImage で入れてる人の方が多数派だっと思うが俺はあんなん使う気もならんしのでどうするかは知らん、ストレージ単価がクソ高い時代に容量を無駄に喰うコンテナ技術は滅びろ。

Chrome や Edge の場合はポリシーファイルにアドオン ID しか書けないので、ストアから古いバージョンをインストールできないと思われる。
たぶん
[公式](https://github.com/bitwarden/clients/)
から 2026.10.0 の .crx 取ってくるしかねえんじゃねえかな、使ってないから知らん。

なんか今回の件も含めあまり公式にいい印象無いんだよな、今年の 4 月には npm 経由のサプライチェーン攻撃でトロイ許してるし。
今週もダウンロードリンクの短縮 URL にドメイン失効した外部サイト使ってましたテヘペロとか言い出しやがって何も反省していない…

俺は WEB エンジニアが脳死で CDN JavaScript/Web Font 使う風習もサプライチェーン攻撃の危険性とプライバシー問題があるから死ぬほど嫌いなんだよね。
だから上のポリシーファイルにもあるブラウザアドオン
[Decentraleyes](https://decentraleyes.org/)
は自衛のために必須なのである。

しかし Bitwarden もオープンソースライセンスと商用ライセンス分離した時点で先行きが暗そうなので乗り換え先探した方がいいかもね。
とはいえ以前パスワードマネージャを検討した時、Bitwarden 以外は有償プランじゃないと厳しいって結論出てるからな。

* [Bitwarden](https://bitwarden.com/)
  * [いいところ]
    * 悪の枢軸ステイツ以外のサーバが選べる(EU)
    * オープンソースでセルフホストも可
    * サーバサイド実装は Rust で書かれたクローン Vaultwarden もある
    * SSH 鍵管理が無償
    * SSH-Agent 機能が無償
    * カスタムフィールドが無償
    * CLI ツールがある
  * [悪いところ]
    * サーバが悪の枢軸ステイツ企業の MS Azure 上にある
    * ここ最近商用版とソースコードが分岐しいつまでオープンソースが続けられるか暗雲たちこめる
    * 貴重なメモリを食い尽くす Node.js/Electron で書かれている
    * 統合されたオンラインワンタイムパスワード (OTP) 生成器が有償
    * パスワード流出アラートが有償

* [Zoho Vault](https://www.zoho.com/jp/vault/)
  * [いいところ]
    * 悪の枢軸国ステイツ以外にサーバがある
    * 詳細な監査ログが残るので不正使用に気づきやすい
    * SSH 鍵管理が無償
  * [悪いところ]
    * 完全クローズドなのでベンダロックインされる
    * 日本からだと悪の枢軸国ステイツの属国日本以外のサーバが選べない
    * SSH-Agent 機能 なし
    * scheme の無い URL が登録できない、そのため認証 URL がパッケージ名となる Android アプリで入力補助が働かない
    * 主キーがドメイン名(ラベル) + ユーザ名でなくドメイン名(ラベル)なので、同一ドメインに複数のログイン ID があるようなデータのインポートに注意が必要
    * パスワード流出アラート機能なし(前はあった記憶があるので廃止になった？)

* [Proton Pass](https://proton.me/pass)
  * [いいところ]
    * クライアントがオープンソース
    * 悪の枢軸国ステイツ以外にサーバがある(スイス)
    * CLI ツールがある
  * [悪いところ]
    * サーバはクローズドでセルフホスト不可
    * SSH 鍵管理が有償
    * SSH-Agent 機能が有償
    * カスタムフィールドが有償 (Android アプリは無償)
    * 統合されたオンラインワンタイムパスワード (OTP) 生成器が有償 (Androind アプリは無償)
    * デスクトップクライアントが Windows 10 1903 より以前で動作しない

[Nord Pass](https://nordpass.com/)
はみるからに機能不足なのでアカウント作るとこまで至らず。
[KeePassXC](https://keepassxc.org/)
はクラウド機能無くて別途ネットワークストレージが必須になるからやはりパス。

ということで無課金縛りだとスマホオンリーなら Proton Pass でデスクトップで SSH も使うなら Bitwarden やね。

まぁこのインフレで食料品の値段だけで鬱になれる世の中で月数ドルをパスワードマネージャに払える人は
[1Password](https://1password.com/)
と Proton Pass で悩んでくれ、試用版使った限りじゃ 1Password いいとこ見つけられなかったわ。
